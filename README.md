# FS25_ContractParms
Mod to set parameters for all Farming Simulator contract types

### Beta
This first release is a rather crude implementation, allowing the player to adjust reward parameters for each contract type. 
This is done by editing `reward.lua` inside the mod folder.

The version also supports contract types added by other mods, like FS25_AdditionalContracts.

### Future planning
I intend to augment this with
- UI settings page
- persisting  a players settings in the savegame folder
- adding other contract parameters, like max instances
